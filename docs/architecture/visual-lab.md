# 3D Visual Lab

`/game/visual-lab` is an authenticated inspection surface that uses the same hero manifest, `GLTFLoader`, cloned skeletons, materials, animation controller and VFX manifests as showcase and arena.

It exposes all four starters together or separately, drag rotation, wheel zoom, showcase/top-down cameras, three backgrounds, three quality tiers, wireframe, skeleton helpers, the thirteen clips, pause/speed and a crossfade sequence. All sixteen starter skills can run through anticipation, delivery, impact and dissipation; the burst control and stress scene expose active/capacity/idle/rejected values for every bounded pool plus renderer counters.

The checklist is intentionally observational. Only successful asset loading is marked automatically. Ground contact, silhouette, materials, animation, camera, VFX, draw calls and FPS stay unapproved until a person observes a WebGL-capable browser. If WebGL initialization fails, the route keeps its manifest, loading/error and checklist controls available without claiming visual approval.

Current environment evidence: no installed Chromium, Chrome or Firefox executable was found, no Playwright browser cache was present, and the supervised cloud browser reported WebGL unavailable. The lab shell was observed there; the GLB render itself was not.

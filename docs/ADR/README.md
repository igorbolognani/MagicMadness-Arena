# Technical ADRs

ADRs record technical deviations or baselines only. Product decisions remain
in the canonical pack and require an explicit new product decision to change.

ADR-003 is retained as a historical record of the first-session 2D fallback and
is superseded by ADR-004 and ADR-006 for the current Three.js/WebGL client.

- ADR-007 records the Worker/D1 hosted-account boundary.
- ADR-008 records the original elemental 3D client and reference-use boundary.
- ADR-009 records signed, replay-resistant authoritative match-result receipts.
- ADR-010 records the signed session, reconnect and deployment boundary for Verified Vs Bots.
